
# 📊 Flipkart Dashboard Project

## 📝 Overview
This project showcases an **interactive Flipkart-themed dashboard** built for analyzing e-commerce data.  
The dashboard includes:
- Key Performance Indicators (KPIs)
- Revenue trends
- Category performance
- Seller analysis
- Delivery insights
- Geographic revenue distribution
- Actionable recommendations

---

## 🎯 Features
- **Flipkart Branding** (Blue & Yellow theme)
- Filters for:
  - Brand
  - Payment Modes
  - Returnable status
- Visualizations:
  - Line charts for revenue trends
  - Bar charts for category & seller performance
  - Treemap for delivery days
  - Map for revenue by city
- Recommendations section for decision-making
